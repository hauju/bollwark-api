This is a Bollwark instance

A cookie-free proof-of-work CAPTCHA service. There is nothing to use here directly: sites embed its widget and verify submissions against its API.

Embed the widget

Add a container to the form and load the script from this host:

<div data-sitekey="<SITE_KEY>"></div>
<script src="https://<this host>/v1/widget.js"></script>

Then verify the submitted token server-side with POST /v1/verify and the site secret.

For the operator

  • Test page: try the widget end to end
  • Admin dashboard: needs ADMIN_TOKEN
  • Health check
