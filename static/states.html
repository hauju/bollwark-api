Bollwark Widget — State Gallery

Visual reference for every tier / state combination the embeddable widget renders. The puzzle-time risk score determines the tier; the widget then either runs proof-of-work invisibly, prompts the visitor to click a checkbox, or surfaces a blocked message.

Default mode data-mode unset

The widget always renders chrome (checkbox row + brand footer). The visible UX is uniform across pass tiers — visitors see the same "I'm not a robot" → spinner → "Verified" sequence regardless of score. The only behavioural difference: on invisible_pass the widget auto-runs the spinner without a click; on checkbox / hard_pow it waits for a click. Visitors can't tell which tier the server picked.

Invisible mode data-mode="invisible"

No chrome renders for low-risk visitors. The widget only materialises a UI when the tier requires user interaction. On block-tier the widget renders nothing — embedders must listen for bollwark:puzzle (detail.ok=false) to surface a failure message.
